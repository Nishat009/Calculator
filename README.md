# Orbit Scientific Calculator

A responsive scientific calculator built with React and Vite. It evaluates typed expressions and supports trigonometry, hyperbolic functions, logarithms, roots, powers, factorials, constants, percentages, and modulo.

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

## Features

- DEG/RAD angle modes, inverse trigonometric and hyperbolic functions
- Parentheses, implicit multiplication, operator precedence, powers, factorials, percentages, and modulo
- π, e, previous answer, and memory controls (MC, MR, M+, M−, MS)
- Live expression results, backspace, clear-entry, and calculation history saved in the browser
- Keyboard input: digits, decimal, `+ - * / ^ %`, parentheses, `Enter`, `Backspace`, and `Escape`
- Responsive layout for desktop and mobile screens
